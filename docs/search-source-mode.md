# 搜索、替换与同区域源码模式

- `Ctrl+F` 打开临时搜索栏，`Ctrl+H` 打开替换栏；`Esc` 关闭并回到正文。
- 搜索栏悬浮于画布右上角，不改变画布尺寸或正文断行；左侧箭头展开/收起替换，输入框内 `Aa` / `ab` / `.*` 对应大小写、整词和正则。
- 浅色/深色皮肤跟随软件主题；主题在标题栏切换，搜索面板不再通过右键切换主题。完整结果或错误提示保留在计数的悬停提示中。
- `F3` / `Shift+F3` 或搜索框中的 `Enter` / `Shift+Enter` 向后/向前查找，到末尾循环。
- `Ctrl+/` 切换同一区域的 Markdown 源码/实时预览。搜索栏也提供切换按钮。
- 搜索原文，包括折叠的 Markdown 标记、链接地址、公式与图片源码；不能在预览中精确显示的标记会自动进入源码模式。
- 支持区分大小写、Unicode 整词与 .NET 正则（多行、200 ms 超时）；正则替换支持 `$1`、`${name}`、`$&`。
- 全部替换不会搜索新插入的文本，是一个撤销组；保留未被删除的段落样式锚点和原始换行。
- 源码模式是原生等宽、左对齐、字形簇安全的软换行；不渲染公式、图片、表格或格式标记。不使用第二份文本模型或 WebView。
- 模式切换不修改文档、脏标记或撤销历史。滚动锚点沿用源码坐标；同一区域编辑后切回预览显示最新内容。
- 搜索/替换计划在后台执行，过期版本不会应用。超过 100000 结果时明确提示并拒绝部分“全部替换”；可缩小范围或逐项替换。仅绘制视口内至多 512 个匹配高亮。

验收：搜索 `\sqrt` 与 `**`；查找上下项；单项/全部替换后 Ctrl+Z/Y；切换模式核对光标、滚动与未保存标记；中文输入、长按删除、缩放、表格/公式及窗口键回归。

替换按钮使用 Microsoft [Codicons](https://github.com/microsoft/vscode-codicons) 的 `replace` / `replace-all` 矢量图标，按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 授权；SVG 路径转为原生 XAML 并沿用浅色/深色主题色。授权与修改说明随应用保留于 `Assets/Codicons/NOTICE.txt`。
