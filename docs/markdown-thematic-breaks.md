# Markdown 分割线

原生编辑器现已显示 CommonMark 解析器确认的分割线：独占一行的 `---`、`***`、`___` 及允许的间隔/缩进形式。不会把 Setext 标题下划线、表格分隔行、围栏或缩进代码中的标记误画成横线。

样式直接对应用户提供的 github-markdown-css `hr`：厚度 `.25em`，上下边距 `1.5rem`（24 DIP），横向填满所在容器的可用宽度，无额外边框；浅色 `#d1d9e0`、深色 `#3d444d`。缩放沿用文档变换，切换主题不改变几何。

非聚焦时按一个原子对象显示；点击两侧或用方向键进入后展开原始标记，移出后恢复横线。选择、复制和删除仍映射到完整源码，文件保存不改写标记及换行；源码模式保持原文。引用/列表中的横线保留容器缩进，PDF 沿用屏幕绘制路径和受保护分页带。

验证：新增 24 项专项测试；Debug/Release 各 1016 项单元测试通过。一次性离屏原生验证通过 189 项检查，覆盖三种正文宽度、浅/深色、100%/200% 缩放的实际像素颜色和抗锯齿厚度、缓存重排及源码展开/折叠。PDF 分页带有独立回归测试；本轮不生成安装包。
