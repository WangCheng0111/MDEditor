# MDEditor 软件介绍与使用指南

MDEditor 是一款 Windows 原生 Markdown 编辑器，面向需要同时编写中文、英文、代码与数学公式的用户。它把编辑和阅读放在同一个内容区：平时显示排版后的文字，进入格式或公式时展开相应源码，离开后重新显示排版效果。

正文、代码和数学公式采用原生绘制，不依赖浏览器或 WebView。软件使用 GitHub 风格的浅色与深色 Markdown 样式，提供本地文件保存、搜索替换、图片粘贴、恢复草稿与矢量 PDF 导出。

## 1. 适用场景与主要能力

MDEditor 适合编写技术笔记、项目说明、课程讲义、含公式的学习资料及日常 Markdown 文档。

| 能力 | 使用效果 |
| --- | --- |
| 实时 Markdown 编辑 | 同一区域编辑标题、强调、链接、列表、代码、表格等语法，保留 Markdown 原文 |
| 中英文原生排版 | 中文标点禁则、中西文自然间距、英文断词及段落两端对齐 |
| 数学公式 | 行内和独立公式、分式、根式、上下标，以及支持范围内的数学命令 |
| 代码高亮 | 使用离线 starry-night 高亮资源；已识别语言显示语法颜色 |
| 图片与引用 | 本地图片、剪贴板图片、脚注、公式编号与交叉引用 |
| 文档管理 | 新建、打开、保存、另存为、未保存提醒、外部修改检查及恢复草稿 |
| 搜索与源码 | 浮动查找/替换、大小写与整词匹配、正则表达式、同区域源码模式 |
| PDF 与无障碍 | 共享屏幕布局的矢量 PDF，以及供 Windows 辅助技术使用的文本和选区接口 |

当前重点验证环境为 Windows 11 x64。源码提供 x86、x64、ARM64 配置，但其他架构和目标电脑的安装可用性应以发布者实际验证为准。

## 2. 安装与快速上手

### 安装

使用发布者提供的完整安装包及对应依赖。普通用户不需要安装 Visual Studio、.NET SDK 或系统 Node.js 来编写文档；不要只复制主程序 EXE，也不要删除安装目录中的数学服务、字体或离线高亮资源。

如果安装时出现签名不受信任、架构不匹配或缺少 Windows App Runtime 的提示，请联系发布者确认安装包与依赖。不要通过删除随包文件解决此类问题。

### 开始第一份文档

1. 启动 MDEditor，按 **Ctrl+N** 新建文档；已有文件用 **Ctrl+O** 打开。
2. 在内容区输入文字，或粘贴下面的示例。
3. 按 **Ctrl+S**，选择文件位置并保存为 Markdown。
4. 点击格式文字或公式查看、修改源码；点击其他正文后查看排版效果。
5. 按 **Ctrl+F** 查找内容，按 **Ctrl+Shift+E** 导出 PDF。

```markdown
# 我的第一份笔记

这是一段**加粗**、*强调*和 `inline code`。

行内公式：$\frac{x+1}{\sqrt{y+1}}$。

- [ ] 阅读资料
- [x] 创建文档
```

正常启动时默认显示空白的未命名文档，不插入测试样张。若上次存在未保存的恢复草稿，软件会先询问是否恢复；恢复不会自动覆盖原文件。

## 3. 界面、主题与缩放

内容直接显示在窗口背景上；标题栏下方没有常驻编辑工具栏，主要操作通过快捷键完成。

- 标题栏显示文件名；出现 `*` 表示有未保存修改。
- 标题栏右上角、最小化按钮左侧的主题按钮用于切换浅色/深色，图标随主题变化。
- 首次使用、尚未保存手动主题偏好时，默认跟随系统。手动选择的浅色/深色主题会在后续启动时保留。
- 底部状态栏显示就绪状态、缩放比例和需要关注的文件、资源或排版提示。
- 最小化、最大化/还原、关闭、标题栏拖动及 Windows Snap 用于正常管理窗口。

按 **Ctrl+滚轮** 或 **Ctrl+加号/减号** 调整编辑缩放，范围为 50%～300%；**Ctrl+0** 恢复 100%。普通滚轮用于滚动文档。

缩放或改变窗口宽度会重新选择断行，而不是把整张页面截图放大。正文非末行按排版规则对齐，末行自然收尾；标题、代码、表格单元格及独立公式有各自的布局规则，不统一强行拉伸。

## 4. Markdown 编辑

### 源码与排版效果

实时预览模式会隐藏可折叠的格式标记；进入相应位置时展开源码供编辑，离开后折叠。保存的是 Markdown 原文，不是截图或内部渲染结果。

按 **Ctrl+/** 在源码模式与实时预览之间切换。需要检查标记、复杂嵌套或资源路径时，源码模式更直接；切换模式不会改写文档内容。

### 标题、文字与链接

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

**加粗**，*强调*，~~删除线~~，`行内代码`。

[链接文字](https://example.com)
```

一级和二级标题采用 GitHub 风格的底部分隔线；三级至六级标题不加这条线。行内代码使用等宽文字与圆角底色。

选中文字后可使用 **Ctrl+B** 加粗、**Ctrl+I** 强调、**Ctrl+K** 添加链接、**Ctrl+Shift+X** 删除线。格式操作可以撤销和重做。

### 引用、列表与任务

```markdown
> 这是一段引用。

- 无序项目
  - 嵌套项目

1. 第一项
2. 第二项

- [ ] 尚未完成
- [x] 已经完成
```

在项目末尾按 Enter 会续项；有序列表递增序号，新增任务项为未完成。空项目再次 Enter 可退出列表。Tab/Shift+Tab 调整支持的列表缩进，行首 Backspace 可退回一层结构。任务复选框可直接点击切换，修改同样进入撤销历史。

### 分割线

以下写法可生成独立的 Markdown 分割线，使用 GitHub 风格的颜色与间距：

```markdown
上面的正文。

---

下面的正文。
```

也支持独立一行的 `***` 或 `___`。在空白行输入完整标记后，无需再按 Enter 就会显示分割线；点击分割线仍可展开标记继续编辑。建议在分割线前后保留空行，避免 `---` 紧接文字时被解析为 Setext 标题。代码块内的这些字符仍然是代码。

### 代码块与离线高亮

使用围栏并写明语言：

````markdown
```python
for i in range(1, 5):
    print(i)
```
````

软件支持反引号/波浪号围栏及缩进代码块；代码显示等宽文字、圆角背景与语言标记。代码块中可以直接输入或粘贴代码，Markdown 和公式标记作为代码保留，不转成正文对象。

高亮由随软件提供的 **starry-night** 离线资源处理，不需要联网下载语法。已识别的语言显示语法颜色；未知或未支持的语言保留普通等宽文本。颜色准备在后台进行，不改变代码内容。

### 表格

```markdown
| 名称 | 数值 | 说明 |
| :--- | :---: | ---: |
| 中文 | 42 | a\|b |
| `code` | 100 | **加粗** |
```

列的对齐方式由分隔行决定：

| 写法 | 对齐 |
| --- | --- |
| `:---` 或 `---` | 左对齐 |
| `:---:` | 居中 |
| `---:` | 右对齐 |

如需所有列居中，把各列分隔符都写成 `:---:`。不同列不是按内容是否为数字自动选择对齐。

点击单元格可编辑；Tab/Shift+Tab 切换单元格，末格 Tab 可新增行，单元格内 Enter 可插入行。单元格中的字面竖线需按 Markdown 规则转义为 `\|`；表格源码、样式和撤销记录保持同步。

## 5. 数学公式、脚注与编号

### 公式写法

支持四种数学分隔方式：

| 类型 | 写法 |
| --- | --- |
| 行内公式 | `$x+1$` 或 `\(x+1\)` |
| 独立公式 | 独立行的 `$$...$$` 或 `\[...\]`，也可用独立分隔行包围多行源码 |

例如：

```markdown
原生两端对齐及公式$\frac{2x+1}{\sqrt{y+1}}$仍然保留。

$$
\frac{2x+1}{\sqrt{y+1}}
$$
```

输入或粘贴公式源码后，正常文档会显示排版公式。进入公式可编辑源码；离开后重新折叠。常用分式、根式、上下标及支持的数学符号可与正文共同排版。

软件区分源码中的实际空格与视觉排版间距：手动输入的空格会保留；公式或中西文自然间距不应生成额外的可编辑空格。

数学解析并不是完整 LaTeX 环境，不支持任意宏包或命令。不支持或不完整的公式会保留源码并提示错误位置；修正语法后再查看渲染，不应通过删除整份文档来恢复。

### 复制与粘贴公式

使用 **Ctrl+C** 复制公式或“文字＋公式”，再用 **Ctrl+V** 粘回 MDEditor，可继续以 Markdown 公式编辑和渲染。复制内容保留可编辑的公式源码，因此 Windows 剪贴板历史或普通文本软件看到 `$\frac{...}{...}$` 属于文本表示，不等于公式丢失。

当前没有另一套 Ctrl+Shift+C 复制入口。需要对外交付渲染结果时，可使用 PDF 导出；不要把普通文本粘贴等同于公式图片导出。

### 脚注与公式交叉引用

```markdown
正文的补充说明[^detail]，再次引用同一脚注[^detail]。

[^detail]: 这里写脚注说明。

$$
\frac{x+1}{\sqrt{y+1}}\label{eq:ratio}
$$

见公式 \eqref{eq:ratio}。
```

同一脚注标识使用同一编号。带标签的公式可以编号并通过 `\eqref{...}` 引用；修改相关定义或标签后，引用显示随之更新。

## 6. 本地图片与剪贴板图片

Markdown 图片写法：

```markdown
![图片说明](assets/example.png)
```

相对路径以 Markdown 文件所在目录为基准。软件当前只加载本地/安装包图片，不会主动下载 `http://` 或 `https://` 图片。资源不存在时显示明确占位提示，图片源码仍保留。

将截图等图片复制到剪贴板后，在正常正文按 **Ctrl+V** 可插入图片；也支持剪贴板中的单个本地图片文件。代码块内的图片语法按代码处理，不作为正文图片显示。

- 已保存文档的粘贴图片会写入同目录的 `assets` 附件目录，并以相对 Markdown 路径引用。
- 未保存文档先使用应用本地图片存储；首次保存时，软件会整理相应附件路径。
- 移动、发送或备份文档时，需同时携带它引用的图片和附件目录。
- 仍被正文、撤销记录或恢复草稿引用的图片不是无用缓存，不要随意删除。

为避免异常资源耗尽内存，软件会限制过大的剪贴板图片。遇到提示可先缩小图片，或保留原图文件再使用本地路径引用。

## 7. 查找、替换与源码模式

按 **Ctrl+F** 打开内容区右上角的浮动查找面板，按 **Ctrl+H** 展开替换。面板不占用正文排版宽度，颜色随浅色/深色主题变化。

选中一段文字后按 Ctrl+F，会把所选文字带入查找。F3/Shift+F3 查找下一项/上一项；查找框中 Enter/Shift+Enter 也可导航。Esc 关闭面板并返回正文。

| 面板选项 | 作用 |
| --- | --- |
| Aa | 区分大小写 |
| ab | 整词匹配 |
| .* | 正则表达式 |
| 替换 | 替换当前匹配 |
| 全部替换 | 一次处理全部匹配，可整体撤销 |

搜索针对 Markdown 原文，也包含隐藏的格式标记、链接地址和公式源码。命中隐藏内容时可能需要切换或展开源码；这不是搜索了另一份文档。

正则表达式使用 .NET 规则。替换文本可用 `$1`、`${name}`、`$&` 等表示捕获内容；无效或超时的表达式会提示错误。全部替换不会递归搜索刚替换出来的文本。

## 8. 保存、修改提醒与恢复

可打开 `.md`、`.markdown`、`.mdown`、`.mkd` 和 `.txt` 文本文件；保存/另存为主要使用 Markdown 文件扩展名。

- **Ctrl+S** 保存当前文档，**Ctrl+Shift+S** 另存为。
- 保存保留 Markdown 源码、Unicode 内容及文档的换行信息，不把原文替换成 HTML。
- 标题的 `*` 表示未保存；撤销到已保存内容时，修改标记随之更新。
- 新建、打开其他文档或关闭窗口遇到未保存修改时，提供保存、不保存、取消的选择。
- 如果磁盘文件在外部被修改，软件会检查冲突，避免直接静默覆盖；请按提示确认处理方式。

编辑后短暂停顿，软件会在本机写入恢复草稿。非正常退出后再次启动，可按提示恢复或丢弃；恢复内容仍需主动保存到正式文件。

恢复是本地的尽力保护，不是云同步、版本管理，也不能保证突然断电前的最后一次按键已经记录。重要文档仍应定期保存和备份。不要把应用恢复目录当成临时垃圾清理。

## 9. 导出矢量 PDF

在正文按 **Ctrl+Shift+E**，选择 PDF 保存位置。导出前请完成输入法组词，等待当前排版、图片和代码颜色就绪。

PDF 复用当前文档的屏幕排版，包括窗口宽度所确定的断行、主题、字体及源码展开状态。建议先调整窗口和缩放、确认效果，再导出；如希望只输出渲染结果，应先返回实时预览并离开正在展开的源码。

- 内容横向缩放到 A4 宽度，纵向分页尽量避开文字行、表格行、公式和图片；超高单个对象可使用加长页。
- 正文使用可选择的矢量字形，数学保留矢量几何；不是把整页截图放入 PDF。
- 本地图片仍是像素图，并保留其透明度。
- 纸张使用当前主题背景，不导出桌面亚克力、标题栏、状态栏、光标、选区或搜索面板。
- 缺失图片会保留资源提示；导出也不会联网下载远程图片。

当前不自动添加页码、不跨页重复表头，也不生成可点击链接注释或带完整语义标记的无障碍 PDF。PDF 中的公式是渲染结果，不等同于复制可编辑 TeX；复杂双向文字的复制顺序还受阅读器影响。

导出不代替 Markdown 保存，也不改变原文或撤销历史。准备期间继续编辑可能取消本次导出；完成编辑后重新执行即可。

## 11. 本地数据、辅助功能与功能边界

文档、图片附件、主题偏好和恢复草稿均在本机管理。当前编辑、公式和高亮链路不需要 CDN；没有文档云上传、云同步或多人协作功能，远程图片加载也未启用。

软件提供 Windows UI Automation 的文档文本、选区和光标范围接口，可配合讲述人等辅助技术使用。朗读与文本查询基于可编辑源码，可能包含 Markdown 标记或 TeX；目前不承诺数学自然语言朗读、完整表格/图片对象导航或无障碍认证。

软件支持的是 CommonMark 与约定的 GFM 扩展范围，不是 GitHub 网站的完整执行环境，也不是完整 LaTeX 排版系统。长文档按视口绘制，布局仍在后台处理整篇文档；文档规模、长行、图片和公式复杂度会影响耗时，不应把特定测试文档的速度视为所有文件的保证。

## 12. 常见问题与反馈

**为什么表格三列不是全部居中？**

由分隔行的冒号决定。把三列都改为 `:---:` 即可。

**为什么复制公式后，剪贴板显示公式文本？**

复制保留可编辑 Markdown/TeX。粘回 MDEditor 可再次渲染；需要可阅读的对外交付文件时使用 PDF。

**为什么图片在另一台电脑上不可用？**

检查是否一起复制了图片附件，及相对路径是否仍正确。远程图片当前不会下载。

**为什么改了窗口宽度，行尾位置会变化？**

正文重新断行并执行排版，不是固定图片；这是编辑缩放与窗口重排的正常行为。

**出现“排版失败”或文件操作失败怎么办？**

先记录状态栏的完整提示和触发操作，不要删除恢复草稿或覆盖重要原文。可以检查源码、资源路径，并尝试扩大窗口或恢复 100%。若问题仍存在，提供最小复现文档和操作顺序给发布者。

反馈时建议附上软件版本、Windows 版本、主题与缩放比例、具体操作、预期与实际结果，以及必要截图。发送前移除私密文字、图片和路径；不要公开完整敏感文档。
