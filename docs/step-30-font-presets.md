# 步骤 30：字体预设与高级排版调校

## 实现

- 工具栏新增“字体”预设：默认“均衡”保留各样张原有的西文字体与字号，中文显式使用 Microsoft YaHei；“书刊”正文西文使用 Cambria，中文使用 SimSun，段内行进距从 1.30 增至 1.38。标题倍率维持 H1–H4 的既有层级。
- 中日韩字形覆盖按完整 Unicode 字素簇生成；拉丁文连字、组合重音、阿拉伯文、希伯来文及 emoji 不被拆开，仍交给 DirectWrite 选择字体。诊断样张里的 Gabriola/Segoe UI 西文面保持独立，中文也随预设变化。实际字体必须存在于系统；缺字由 DirectWrite 回退，不能承诺不同机器完全相同的字形。
- 普通段落、代码、表格、可编辑行内公式周围的文字和旧版只读 `MARKDOWN BODY` 数学样张均使用同一预设。数学公式仍由 Cambria Math/OpenType MATH 排版，行内 20 DIP、独立 26 DIP；代码仍用 Cascadia Code，切换预设不改公式或代码的字形身份。
- 原生塑形在候选行测量和最终绘制时使用相同的字素簇字体覆盖。字体预设参与段落会话/稳定行高缓存键，旧异步排版结果被预设修订号拦截，避免旧字体结果覆盖新选择。屏幕 DPI 与编辑缩放仍不改变文档空间字号。

## 验证

- 隔离构建副本的 x64 Debug/Release 主程序均成功；保留原有 `MainWindow.xaml.cs` 的 CA1416 版本警告，本步骤未修改最低系统版本。
- Debug/Release 各 823 项 Core/排版测试通过，新增 3 项覆盖预设规则、连续 CJK 标点及 Unicode 字素簇安全。MTP 项目须直接运行测试可执行文件；此环境的 `dotnet test` 包装调用误报零项。
- VS x64 Release 实际窗口确认工具栏可切换书刊、正文与 `MARKDOWN BODY` 中文呈宋体风格，公式/代码保持正常且状态栏无排版失败；用户复测反馈“正常了”。

## 边界

预设目前仅作用于当前编辑会话，不写入文档或持久化配置；文件保存与重新打开属于步骤 31。首次使用不同字体/宽度仍需原生重新塑形、测量和断行，不能把字体切换说成零耗时。临时 QA 安装已移除；隔离构建副本只用于本步骤验证，结束后清理。
