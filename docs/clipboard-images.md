# 本地剪贴板图片

Ctrl+V 支持系统位图（包括截图、画图等软件复制的图片）和单个本地图片文件。
普通文本、公式源码、代码粘贴仍使用原来的编辑事务。图片不上传、不请求网络。

- 图片由 Windows 图像解码器解码，再编码为 PNG，保留透明度和显示方向。
- 已保存文档：写入文档目录的 `assets/mdeditor-image-<GUID>.png`，插入 `![image](assets/...)`。
- 未保存文档：先写入应用 LocalFolder 的 `ClipboardImages` 持久目录，插入编码的 `file:///...` 地址。
- 首次保存：仅转换应用自己生成的图片地址为相对地址，复制附件到文档旁。
- 另存为：复制应用生成的附件到新文档旁，不移动/覆盖原附件或用户手写图片链接。
- 撤销、重做、自动恢复可能仍引用旧附件，所以已提交附件不是可随意清理的缓存。
- 异步粘贴期间若文档、光标、焦点或保存目录改变，不插入到错误位置，并删除未提交附件。
- 图片像素数最多 4000 万，最终 PNG 最多 16 MiB；损坏/超限图片给出状态提示，不修改正文。
- 不自动转换代码块里的 Markdown 图片语法；代码块保留字面源码。

保存时仍按原有版本/磁盘指纹执行。若保存期间继续输入，保存计划不覆盖新文本，文档保持修改状态。
保存期间暂停新增图片附件，防止另存为时出现附件目录竞争；文本编辑不受影响。

手工回归：复制截图→Ctrl+V→查看图片→Ctrl+Z/Y；保存未命名文档→检查相对地址和附件→重开；
另存到不同目录→重开；普通中文、公式与多行代码粘贴；损坏图片和大图提示。
