# 步骤 34：共享布局的矢量 PDF 导出

## 使用

在正文按 **Ctrl+Shift+E**，选择 `.pdf` 保存位置。无需先保存 Markdown，也不增加工具栏按钮。取消选择器不导出；导出不改变源码、文件路径、修改标记、选区、撤销历史或恢复草稿。

导出前提交已结束的输入，等待当前版本的正文、公式、本地图片和代码高亮就绪。输入法仍在组词时不能导出；等待期间改文档会取消这次导出，提示重新执行。后续后台序列化只读取已录制的不可变绘制命令，不读取正在编辑的缓冲区。

## 布局与内容

- 直接录制 `ReflowDocument.Draw` 的生产绘制路径；不重新塑形、不改 Knuth–Plass 的断行与间距、不重新排数学公式。
- 使用当前窗口宽度、字体预设、主题及源码展开状态。导出前点开了某段语法，PDF 中也会保留该段当前显示状态；源码模式导出的是源码显示。
- 横向整体缩放到 A4 宽度，保持当前断行和相对尺寸。垂直按 A4 分页；不截断可容纳的文字行、表格行或数学/图片原子盒。单个原子对象比一页还高时使用加长页，不丢掉其下半部分。表格可以跨页，本步不自动重复表头，不添加页码。
- 文本使用已塑形 glyph ID、实际 advance/offset 和真实轮廓，嵌入 Type3 矢量字体及 ToUnicode。中文、连字、组合字符可以选择；支持 ActualText 的阅读器可以读取 RTL run 的逻辑文本。复杂双向文字和跨公式复制的阅读顺序仍由 PDF 阅读器决定，本步不是 tagged PDF / PDF-UA 导出。
- 分式、上下标、根号和分隔符保留原生矢量几何；根号延伸横线使用屏幕上的同一合并轮廓。公式可以放大，不栅格化成截图。公式结构并未变为 PDF 数学语义，复制公式不等同于复制可编辑 TeX。
- 圆角代码背景、表格线、链接/强调样式、脚注、公式编号与交叉引用复用屏幕绘制；代码高亮沿用当前 starry-night 结果。链接本步是视觉样式，不增加可点击 PDF 链接注释。
- 本地图片仍是原始像素图，保留透明度；文字/公式/框线是矢量。缺失图片保留当前占位提示；远程图片仍不联网下载。
- PDF 纸张使用 GitHub 主题的浅色或深色背景，不复制窗口亚克力背后的桌面，不导出标题栏、状态栏、光标、选区或搜索高亮。

## 实现边界

`MDEditor.Typesetting/Export` 是不依赖 Windows 的分页及 PDF 对象/流写入器；`MDEditor.Native/Export` 将实际 Win2D command list 通过 Direct2D command sink 转为 PDF 字体、路径、裁剪和图片。原生 COM ABI 限定在该目录。

录制在 UI 线程完成，后台线程负责字形轮廓/图片读取、压缩与写盘。目标目录中的唯一临时文件完整写入后才替换所选目标，异常时清理该临时文件；旧文件不会被部分写入覆盖。系统保存选择器可能先创建一个空目标文件，导出失败时请重新导出；不擅自删除用户选择的目标。

不支持的原生混合模式、侧向字形或非常规图像变换会报明确错误，不静默退化为整页截图。未完成/不可行的布局不会输出错误 PDF。页面绘制坐标超过原生安全范围时拒绝导出。导出不新增安装包、外部 PDF 运行时或联网权限。

## 验证

- x64 Debug / Release 主程序构建通过，已有 CA1416 系统版本告警与本步无关。
- Debug / Release 各 984 项测试通过；本步新增 20 项，覆盖对象流、Unicode、字体分组、原生边界、透明图像、取消、文化无关数值和分页。
- 隔离原生 Win2D 测试覆盖中文、拉丁连字、组合重音、双向文字、标题、强调、圆角代码、表格、图片透明度、缺失图片及分式/根号。
- 深浅主题各 5 页均已渲染并逐页检查；15 处公式完整，40 个分页测试段落无丢失或重复。并核对 PDF 文本提取、字体/图片资源与页数。隔离测试没有修改应用草稿或用户 Markdown。
- 最新开发窗口经系统保存选择器成功导出（用户已确认）。实窗产物共 3 页、2049 个可选择字符，2 组嵌入字体及 2 个本地图片资源；已逐页检查公式、表格、starry-night 多色代码、脚注和编号。产物保留在用户自行选择的位置，不作为临时文件删除。

## 人工验收

1. 最新源码 F5，打开需要的 Markdown，等待排版完成，按 Ctrl+Shift+E 保存 PDF。
2. 阅读器内确认文字能选择/复制，放大公式仍清晰、根号连接正确；段落断行与导出时的窗口一致。
3. 核对表格、代码高亮、图片和多页边界；切另一主题导出，确认文字/公式可见。
4. 检查导出后文档 `*`、内容与撤销记录不变；取消保存选择器，正文应保持可编辑。原有输入、删除、缩放和三个窗口键照常回归。
