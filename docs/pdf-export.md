# 矢量 PDF 导出

在正文按 **Ctrl+Shift+E**，选择 PDF 保存位置。无需先保存 Markdown；取消选择器不导出。导出不改变原文、文件路径、修改标记、选区、撤销历史或恢复草稿。

导出前结束输入法组词，并等待当前正文、公式、本地图片和代码高亮就绪。准备期间继续编辑会取消本次导出，需要重新执行。

## 布局与内容

- 录制生产 `ReflowDocument.Draw` 路径，不重新塑形、断行或排数学公式。
- 保留当前窗口宽度、字体、主题和源码展开状态；源码模式导出源码显示。
- 横向缩放到 A4 宽度，保留断行和相对尺寸；纵向分页尽量不切断文字行、表格行、公式或图片。超高单体使用加长页。
- 中文、连字和组合字符使用原生字形轮廓、Type3 矢量字体及 ToUnicode。数学保留矢量几何，不生成整页截图。
- 代码、表格、脚注、编号和分割线复用屏幕绘制；本地图片仍为像素图并保留透明度。
- 纸张使用 GitHub 主题背景，不复制桌面亚克力、标题栏、状态栏、光标、选区或搜索高亮。
- 缺失图片保留占位提示；远程图片不联网下载。

## 边界

表格跨页不自动重复表头，不添加页码；不生成 tagged PDF/PDF-UA、数学语义或可点击链接注释。复杂双向文本的复制顺序还受阅读器影响，复制公式不等同于取得可编辑 TeX。

Native 将 Win2D command list 转为 PDF 字体、路径、裁剪和图片；Typesetting 提供纯分页与 PDF 写入器。先录制不可变绘制命令，再后台读取字形/图片、压缩和写盘；临时文件完整后才替换目标，失败时清理临时文件。系统保存选择器可能预先创建空目标，失败后请重新导出。

未完成或不可行的布局、超出安全坐标的对象、不支持的原生绘制模式会明确报错，不静默退化为截图。导出不需要外部 PDF 运行时或网络权限。
