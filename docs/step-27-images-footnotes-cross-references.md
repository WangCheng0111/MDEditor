# 步骤 27：图片、脚注、公式编号和交叉引用

## 已实现

- `![替代文字](路径)` 和 `![替代文字][id]` / `[id]: 路径` 在折叠视图中成为单个图像对象；点击后可查看原始 Markdown。路径可指向应用包内资源或本地文件。图片异步加载，不阻塞输入和初次排版；16 MiB 文件与 4000 万像素上限避免意外占用过多内存。
- 加载中、文件缺失、图片过大和解码失败均有可见占位或状态提示；失败时源文本不变。当前不自动访问网络 URL，远程图片显示“不支持”的状态。
- `[^id]` 与 `[^id]: 内容` 按首次引用顺序编号，同一脚注的多处引用共享编号；缺失定义显示 `[?]` 并报告问题。
- 独立公式中的 `\label{eq:id}` 保留在源文本，但不交给公式绘制；公式右侧显示编号。`\ref{eq:id}` 显示数字，`\eqref{eq:id}` 显示括号数字。标签删除、移位或重复后，编号与未解析状态随源文本重新计算。
- 显示文本与原始 UTF-16 源码的坐标映射保持可逆；选择、删除和编辑折叠对象时不会留下半截 Markdown 标记。

## 本步边界

- 图片相对路径目前相对于应用部署目录；文档打开/保存与相对路径基准属于步骤 31。
- 脚注当前支持单行定义；多段嵌套脚注内容尚未实现。
- 网络图片下载需要新增持久网络能力，本步未启用。
- 图片独占段落时居中；在同段输入文字后改用图文混排并左对齐，缺失图片占位框遵循同一规则。

## 手动验收

1. 启动后正文不应空白或出现“排版失败”；原有 TABLE 仍为三列表格，代码块和公式正常。
2. 滚动到 MEDIA：本地图片出现；缺失图片有红色状态占位，状态栏说明“文件不存在”，不破坏排版。
3. FOOTNOTE：两处引用均显示相同上标，定义前显示同一编号；修改定义内容后上标仍一致。
4. EQUATION：居中公式右侧显示 `(1)`，下方交叉引用也是 `(1)`；修改或删除 `\label{eq:ratio}` 后引用更新为未解析状态。
5. 点击图片、脚注、交叉引用可展开原始源码；移开后重新折叠。Ctrl+Z/Ctrl+Y、缩放、拖宽窗口以及右上角三个窗口键不应出现回归。
