# 步骤 17：键盘编辑与正文重排

## 本步范围

在步骤 16 的原生光标/选区基础上，点击普通正文后可直接键入可打印字符，并用 Backspace、Delete、Enter、Tab 编辑；方向键、Home/End、Ctrl+Home/End 移动光标，Shift 配合导航扩展选区。输入会替换选区。左右移动遵守已呈现布局的视觉停靠点；当新版本仍在重排时，回退到字素安全的逻辑移动。上下移动保留期望水平位置。换行会拆分段落，连续换行可创建空段落；空段落保留可定位的光标行。

编辑的单一事实来源是 Core 的 `StyledDocumentBuffer`：piece-table 原文、行索引和样式锚点作为同一个版本快照发布。Typesetting 的 `TextEditingOperations` 在字素边界执行插入、替换和删除，避免截断组合字符、代理对或 CRLF。Native `ReflowContent` 从快照生成带源码范围的段落；内容变化使旧测量会话失效，最新请求异步求解并原子提交。重排期间上一帧可继续绘制，旧版本光标不会误画到新正文。缩放/DPI 路径和三个自定义窗口按钮保持不变。

本步仍是**可编辑正文验收样张**，不是完整 Markdown 编辑器：画布中的 Markdown 数学段落是独立只读样张，暂不能在公式内部输入。当前文字只在本次应用会话内保存；重新启动会恢复样张。撤销/重做、剪贴板、TSF/中文输入法组合、文件打开/保存、Markdown 语法投影及完整 LaTeX 属于后续步骤。此处的键盘输入不等于宣称输入法已完成。

## 验证

纯测试覆盖样式锚点在插入/删除/段落合并后的迁移、版本一致性、字素与 CRLF 安全删除、选区替换及视觉左右移动。Debug/Release 各 624 项测试通过。真实 x64 WinUI 窗口核对了字母输入、退格、回车拆段与空段落、选区替换、数学样张拒绝输入及原生重排；原生专项测试继续作为既有排版回归。验收时可再手动检查快速连续输入、方向键与窗口缩放/三键交互。

## 后续交互修复

光标和选区现由透明的独立 Win2D 画布绘制，闪烁计时器只使交互层失效，不再每 530 ms 重绘正文和 `CHINESE / punctuation` 标题。正文删除仍使用同一份版本化缓冲区，但连续按键不会反复取消正在运行的断行任务：已完成的较旧编辑版本可以作为临时帧逐步显示，最新版本算出后再原子替换；宽度、缩放或公式内容变化仍阻止过期结果发布。后台原生排版在独立线程执行，完成后由 UI 队列串行发布；中间帧不写完整布局诊断文件，避免诊断 I/O 与输入抢占。Debug/Release 各 627 项纯测试通过；窗口中连续 12 次退格期间，显示布局版本逐步前进，且已由人工确认长按退格时持续显示删除过程、松开后自动对齐，不需额外按键；光标闪烁时标题稳定。
