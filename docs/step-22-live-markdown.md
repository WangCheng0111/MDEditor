# 步骤 22：原生正文实时 Markdown 样式

应用正文现使用步骤 21 的编辑投影：原文快照始终是编辑、撤销与剪贴板的坐标系；排版读取同版本但独立的显示快照。标题、加粗、强调、删除线、行内代码、链接的明确语法标记在光标移出该结构时折叠，点击或移动光标进入结构时展开。正文与公式的命中、选区、光标和候选框位置经投影几何桥接回原文位置；同版本不同展开状态不得复用旧布局。单击松开不重复命中重排后的位置，真实拖选仍可跨格式进行。

字体变化进入 DirectWrite 塑形与 Knuth–Plass 测量：H1–H6 使用标题字号和字重，加粗、斜体与行内代码使用对应字重、字体样式和等宽字体。删除线、链接下划线及代码连续圆角底色按最终行几何原生绘制，不依赖 WebView2。缩放和窗口重排继续使用同一布局快照与源码映射。

工具栏提供正文、H1–H6、加粗、强调、删除线、行内代码和链接。Ctrl+B、Ctrl+I、Ctrl+K、Ctrl+Shift+X 分别对应常用行内命令。命令仅生成目标原文范围的一次替换，能撤销/重做，不重新序列化周围的 Markdown、公式或原始换行；光标处重复使用同一格式命令可移除当前完整包装。链接默认插入可编辑的 `https://example.com` 目标。底部的 MARKDOWN 样张用于人工验收，不改变此前的 CHINESE/ENGLISH/公式样张。

本步不实现链接跳转、文件保存、列表/引用、围栏代码块、表格或图片的结构编辑；它们分别属于后续步骤。Setext 标题可显示与展开，标题格式按钮写入 ATX 标记。混合公式和 Markdown 的统一语法编辑仍以步骤 25 为准。当前无需宣称整套编辑器已经完成。

新增 28 项测试，覆盖显示样式与源码映射、H1–H6、完整/部分包装切换、不完整语法、格式命令只改选区、一次撤销/重做及点击隐藏定界符的光标亲和方向。Debug/Release 全量各 718 项通过，WinUI x64 Debug/Release 构建通过；仍有原有 `AppInfo.Current` CA1416 平台警告。人工 F5 验证了格式显示/展开、点击与拖选、圆角底色、格式按钮、撤销/重做、中英文输入、长按删除、缩放/两端对齐、公式与三个自定义窗口键。
