# GitHub 风格 Markdown 主题

依据用户提供的 github-markdown.css、github-markdown-light.css 和 github-markdown-dark.css，将支持的 Markdown 元素映射为原生绘制规则；不使用 WebView，也不在运行时解释 CSS。

## 外观与主题

默认跟随系统。标题栏最小化按钮左侧的主题键可切换浅色/深色，并同步更新图标。编辑区透明，与标题栏及状态栏共享亚克力背景和半透明主题遮罩；无独立的纯白画布、卡片外框或顶部工具栏。

| 元素 | 浅色 | 深色 |
| --- | --- | --- |
| 正文 | #1f2328 | #f0f6fc |
| 链接 | #0969da | #4493f8 |
| 边框 / 分割线 | #d1d9e0 | #3d444d |
| 代码块底色 | #f6f8fa | #151b23 |

引用、表格、高亮、图片提示、光标、选区与窗口按钮随主题变化。切换只更新画笔和重绘，不改变字形、断行或布局缓存。

## 排版映射

文件文档采用 16 DIP 正文、1.5 行高；H1–H6 相对正文为 2 / 1.5 / 1.25 / 1 / .875 / .85，字重 600、行高 1.25。文件文档的 H1/H2 带底边框，H6 使用次要文字色。内置演示样张保留诊断字号与段落样式，不等同于文件文档的全部标题规则。

引用使用次要文字和竖线；列表保留结构标记和任务复选框。代码块为 85% 正文字号、1.45 行高和 6 DIP 圆角；行内代码按自己的字形盒绘制中性圆角底，不跟随同一行的高大公式拉高背景。表格使用边框和交替行底色；列对齐由原始 Markdown 对齐标记决定。链接用强调色，不设永久下划线。

[Markdown 分割线](markdown-thematic-breaks.md)遵循 hr 的 .25em 厚度和 1.5rem 上下边距。公式与普通文字共同断行，维持原生两端对齐、中文禁则及英文断词规则。

HTML 专属元素和浏览器交互不自动由主题引入。正文布局仍使用原生排版，不以浏览器默认规则替换核心功能。
