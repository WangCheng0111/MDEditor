# GitHub 风格 Markdown 主题

依据用户提供的 `github-markdown.css`、`github-markdown-light.css` 和 `github-markdown-dark.css`，将当前支持的 Markdown 元素转换为原生绘制规则；不使用 WebView，也不在运行时解释 CSS。

## 配色与选择

后续 UI 精简已移除顶部工具栏、画布卡片外框和画布实色底。内容区透明，标题栏、编辑区和状态栏共用窗口原有的亚克力背景及同一层半透明主题遮罩，避免上下区域出现不同的底色；不再添加独立的纯白画布。编辑器仍默认跟随系统并读取已有主题设置，字体/主题设置逻辑保留为界面接口；下列工具栏选择项为主题初次验收时的界面记录，当前不再显示。

- 工具栏“主题”：跟随系统 / 浅色 / 深色。未设置时默认跟随系统。
- 手动选择保存于应用本地设置 `MarkdownThemeMode`；系统模式响应 WinUI 的 `ActualThemeChanged`。
- 浅色正文 `#1f2328`，页面 `#ffffff`，链接 `#0969da`。
- 深色正文 `#f0f6fc`，页面 `#0d1117`，链接 `#4493f8`。
- 引用、表格、代码高亮、图片不可用提示、光标、选区及标题栏一并切换。
- 配色切换只更新画笔与重绘，不重新塑形、断行或清空排版缓存。

## 排版映射

新建或打开的文件采用 16 DIP 正文、1.5 行高；H1–H6 相对正文为 2 / 1.5 / 1.25 / 1 / .875 / .85，字重 600、行高 1.25。H1/H2 有底部分隔线，H6 使用次要文本颜色。

引用使用次要文字和左侧竖线；列表保持结构标记和任务复选框。代码块为 85% 正文字号、1.45 行高和 6 DIP 圆角，行内代码使用半透明中性底色及圆角。表格采用边框和交替行底色，保留可编辑单元格的现有命中和宽度规则。链接使用强调色，取消常驻下划线。

公式同段的行内代码背景按代码字形自身的原生文字盒定位，上下各保留 2 DIP；不会跟随分式、根式等造成的整行增高而拉高灰底。

已有开发样张保留原来的诊断字号与段落间隔，但使用新的配色及 Markdown 元素样式。文件文档不显示样张的绿色右边界。

Knuth–Plass 两端对齐、中西文细调、数学字体与原生公式、字体预设、源码映射及实时编辑保持现有实现，不受 CSS 的浏览器默认排版规则替换。HTML 专属选择器（如 details/kbd/Octicon）及链接悬停等浏览器交互不由此主题引入；新增语法支持仍按独立步骤推进。

## 验证

- x64 Release 的原生模块和 WinUI 应用构建通过。
- Debug / Release 各 834 项核心回归测试通过，包括 GitHub 标题字号比例，以及公式旁文字的嵌套样式分段、范围裁剪、无样式和相邻样式合并检查。
- 浅色 / 深色 / 跟随系统的样张配色已由用户确认正常。[外观回归样张](github-markdown-theme-sample.md)保留于项目文档，不包含用户文件。
- 启动和主题的实际窗口检查须使用最新构建；切换字体、缩放和窗口宽度后仍应能编辑，且不出现排版失败。
