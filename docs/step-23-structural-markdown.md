# 步骤 23：引用、列表与任务项的结构编辑

步骤 22 的原文/显示双快照继续作为唯一坐标体系。Core 按物理行记录引用前缀、无序/有序项、任务标记和缩进，并要求列表项的起点得到 CommonMark 解析器确认；围栏代码、缩进代码、分隔线和不能打断段落的 `2. 文本` 不会被误认作列表。未聚焦的结构前缀折叠，聚焦行展开；原文、原始换行及既有格式不重写。

Native 对折叠后的列表绘制圆点/序号/复选框，对引用绘制竖线；正文缩进后仍使用同一 Knuth–Plass 行宽求解，非末行以本行可用宽度对齐到右边界。任务复选框可直接点击；工具栏可切换引用、无序、有序、任务类型和勾选状态。

编辑规则：

- 非空项目/引用行按 Enter 续项；有序项递增，并将后续同级有序项一并顺延；已完成任务续项时重置为未完成。当前行原本的换行符类型保持不变。
- 空项目按 Enter 退出列表并保留外层引用；空引用按 Enter 退出一层引用。已有正文内容不被删除。
- 光标在任务正文开头按 Backspace，先移除 `[ ]`/`[x]`；嵌套项目再按 Backspace 向外退一级；最外层项目移除列表标记；引用正文开头则移除一层 `>`。
- Tab / Shift+Tab 调整当前列表项及其显式嵌套子项，或对跨行选区逐行缩进/反缩进；引用行也可用 Tab 增加一层、Shift+Tab 减少一层。一个结构操作只产生一笔可撤销的原文事务。
- 方向键、鼠标命中和 Home 进入折叠列表行时定位到内容侧，不把普通输入插到隐藏标记之前。选择完整可见项目并剪切/复制会包括其原文前缀。

本步针对带明确引用/列表标记的行与显式嵌套子项。列表内未带标记的多段落/惰性续行的专门结构排版、代码块、表格、文件保存等仍在后续步骤处理。点击勾选只替换任务标记中的一个字符；重新勾选写入小写 `x`。
