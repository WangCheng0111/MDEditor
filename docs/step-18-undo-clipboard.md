# 步骤 18：撤销、重做和剪贴板

本步按最初计划表实现可编辑正文的历史与剪贴板。`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；`Ctrl+C/X/V` 复制、剪切、粘贴，`Ctrl+A` 全选当前正文或只读数学样张。数学样张仍只读；`Ctrl+C` 复制保留公式源码的文本，所以公式与相邻文字的混合选区能粘贴回本软件。

历史只保存每组变更的旧/新文本、两端选区和样式锚点，不复制整篇文档。相邻位置、850 ms 内的连续输入、连续退格或连续 Delete 合并；导航、鼠标定位、复制/粘贴、换行和选区替换会分组。撤销和重做一次恢复整组文本、段落样式与选区；文档版本继续递增，旧布局不能覆盖新版本。新编辑清空重做栈，外部未记录的变更使旧历史失效。最多保留 256 组。

正文复制保留所选源码的 Unicode 和原始换行；剪切只在成功写入 Windows 剪贴板后修改正文。粘贴异步读取文本，读期间若选区或文档版本改变则放弃旧请求，避免覆盖用户的新操作。当前原生塑形器不支持制表符，粘贴中的 Tab 与 Tab 键一样转换成四个空格；其他不支持的控制字符会被拒绝并显示提示。

按用户验收要求，提前接入了步骤 20/21/25 的最小可编辑数学链路：正文中的有效 `$...$` 与独占一行的 `$$...$$` 会保留原始 Markdown 源码，由数学工作进程生成原生公式盒，与文字共同断行、选择和缩放。公式连同文字复制粘贴后仍显示公式；把单独的陈列公式粘在句子中间时，会按目标文档的换行风格补齐边界，使它成为居中的独立段落。新公式异步布局完成后替换暂时显示的源码；无效或未闭合语法仍保留源码。光标在已渲染公式的边界执行 Backspace/Delete 会一次删除整个公式，并可撤销。尚未实现公式内部结构化编辑、跨多行 `$$` 源码的可编辑投影、一般 Markdown 富文本或文件持久化；这些仍由后续步骤完成。此阶段也不包含 TSF 输入法。

先前验证：`MDEditor.Core.Tests` 覆盖历史、跨段 CRLF/Unicode、公式选区、混合复制和陈列公式粘贴分行；隔离 Debug/Release 测试各 644 项通过，x64 Release 应用构建通过。真实窗口已验证单公式、公式连同文字、陈列公式句中粘贴、撤销/重做、原子删除和缩放。此后按用户要求移除了公式图片快捷键，保留 `Ctrl+C` 复制公式源码；旧安装包不会自动包含本次修改。
